# Module 12 – Business Analytics Fundamentals and Applications

This repository contains my work for Module 12 of the course.

## Project Overview

This project applies the **four pillars of business analytics** — descriptive, diagnostic, predictive, and prescriptive — to GreenGrocer, a chain of organic grocery stores across five Florida cities. It analyzes a full year of daily sales data alongside customer segment data to produce an executive-level business report with actionable recommendations.

## Files Included

- `module12-assignment.py` – Main Python script containing data generation, all analytics functions, visualizations, and the executive summary.

## What I Practiced

- Performing descriptive analytics to summarize sales performance by store, department, and season.
- Conducting diagnostic analytics to identify correlations between store characteristics and revenue.
- Building a predictive model using linear regression (via SciPy) to forecast store sales.
- Generating department-level sales forecasts and identifying profit opportunity scores.
- Creating data visualizations with Matplotlib to support business findings.
- Writing a structured executive summary with key findings, recommendations, and estimated financial impact.
- Connecting data analysis end-to-end to real business decisions and strategy.
